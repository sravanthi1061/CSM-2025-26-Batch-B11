# CSM-2025-26-Batch-B11

## 📌 IoT-Based Child Safety Monitoring System

## 🔹 Overview
This project is an IoT-based solution designed to monitor and ensure child safety in real time.  
It tracks location, detects falls, and monitors basic health parameters to provide instant alerts.

## 🚀 Features
- 📍 Real-time GPS tracking  
- ⚠️ Fall detection using accelerometer  
- ❤️ SpO₂ health monitoring  
- 🚨 Emergency alert system  
- 🌐 IoT-based remote monitoring  

## 🛠️ Technologies Used
- Microcontroller (Arduino / ESP32)  
- GPS Module  
- Accelerometer Sensor  
- SpO₂ Sensor  
- Embedded C / Arduino IDE  

## ⚙️ How It Works
Sensors collect movement, health, and location data.  
Microcontroller processes data in real time.  
If abnormal activity is detected, an alert is sent to guardians.

  ALERT: Fall detected!
  Acceleration: 27.1 m/s²
